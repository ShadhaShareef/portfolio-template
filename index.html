Career Recommendation System — Resume & Job Match Analyzer

The Problem: Candidates struggle to judge how well their resume fits a specific job description, and generic advice rarely shows the concrete gaps.

The Solution: A machine learning system that analyzes resume text against a job description, weighs skills, experience, and keywords, and returns an eligibility score with explainable gaps.

What I Built: Python pipeline using pdfplumber for PDF text extraction, spaCy for keyword analysis, and a scoring algorithm that turns the comparison into an eligibility score.
